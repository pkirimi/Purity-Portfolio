Diabetes
Risk Prediction

Exploring whether patient-level measurements can support diabetes risk classification.

A supervised machine learning project using the Pima Indians Diabetes dataset to explore classification, preprocessing, model comparison and evaluation.

TYPE Binary Classification
MODELS Logistic Regression · Random Forest
DATASET Pima Indians Diabetes
TEST SET 154 rows
01

THE QUESTION

Can patient measurements help classify diabetes risk?

The project explored whether routinely recorded patient measurements could be used to predict whether an individual belongs to the diabetes-positive or diabetes-negative class.

I treated the task as a supervised binary classification problem and compared different modelling approaches rather than assuming one model would automatically be best.

02

DATA

Understand the inputs before modelling.

The dataset contained clinical and demographic measurements commonly used in the Pima Indians Diabetes dataset.

Pregnancies
Glucose
Blood Pressure
Skin Thickness
Insulin
BMI
Diabetes Pedigree Function
Age

Missing or zero-valued measurements were an important consideration during exploration because they can affect model behaviour if treated as ordinary values.

03

MODELLING

Compare interpretable and ensemble approaches.

I explored Logistic Regression and Random Forest as two different approaches to the classification problem.

MODEL 01

Logistic Regression

A relatively simple and interpretable classification approach.

MODEL 02

Random Forest

An ensemble method capable of modelling nonlinear relationships and interactions.

04

RESULT

Random Forest reached 74.7% accuracy.

RANDOM FOREST ACCURACY 0.7468

On the test set, the Random Forest model achieved approximately 74.7% accuracy.

Accuracy alone does not establish that a model is clinically useful. The result should be interpreted within the dataset, class distribution, evaluation design and intended use.

05

WHAT I LEARNED

Model performance needs context.

This project strengthened my understanding of the end-to-end classification workflow: inspecting data, preparing features, splitting the dataset, training models and evaluating their predictions.

It also reinforced that a single accuracy number should not be treated as proof that a model is ready for real-world clinical use.

01 Data quality affects model quality.
02 Different models capture different patterns.
03 Evaluation must match the intended decision.
