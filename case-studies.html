02 MACHINE LEARNING

MACHINE LEARNING · SEARCH INTELLIGENCE

Search Intelligence

Machine learning work using search intelligence data to identify content that may require review and prioritize a review queue.

Python Pandas Scikit learn Machine Learning
PROBLEM

Large content datasets require a structured way to identify which pages may deserve attention.

APPROACH

Defined the data contract, audited signals, created a rule based baseline and evaluated a Logistic Regression model.

RESULT

The model achieved an F1 score of 0.702, but ROC AUC was 0.515, revealing limited separation between declining and non declining content.

03 MACHINE LEARNING

MACHINE LEARNING · CLASSIFICATION

Diabetes Risk Prediction

A supervised machine learning project exploring diabetes risk prediction using clinical features from the Pima Indians Diabetes dataset.

Python Pandas Random Forest Logistic Regression
PROBLEM

Explore whether patient features could be used to classify diabetes risk.

APPROACH

Cleaned and explored the dataset, trained Logistic Regression and Random Forest models, then evaluated their performance.

RESULT

The Random Forest model achieved approximately 75% accuracy on the test set.
