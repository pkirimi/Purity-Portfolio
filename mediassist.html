MediAssist

Exploring how conversational AI can make clinical information easier to access.

An early AI healthcare assistant project that helped me explore conversational interfaces, clinical reasoning, prompt design and responsible use of AI in healthcare.

ROLE AI Engineer
TYPE Conversational AI
FOCUS Clinical information
LOCATION Kenya
01

THE PROBLEM

Making clinical information easier to navigate.

Healthcare information can be difficult to navigate, especially when people need to translate a symptom or question into something they can actually act on.

MediAssist Kenya was an exploration of how a conversational interface could make interaction with clinical information more natural.

DESIGN PRINCIPLE Use AI to support understanding and navigation, not to replace qualified clinical judgement.
02

HOW IT WORKS

Conversation as the interface.

The application uses a conversational interaction model. Instead of requiring a user to navigate complex menus first, the user can express a question in natural language.

01 User question
02 AI interpretation
03 Response generation
04 User decides next step
03

ENGINEERING

Connecting an AI model to a usable product.

The project gave me practical experience connecting application logic to an AI API and turning model responses into a user-facing experience.

LANGUAGE Python
INTERFACE Streamlit
AI OpenAI API
PRODUCT Conversational assistant
04

WHAT I LEARNED

An AI model is not the product.

Building MediAssist changed how I thought about AI applications. The model is only one component. The surrounding interface, instructions, context, safety considerations and user experience determine whether the capability becomes useful.

It also made the limitations of generative AI more obvious. In a healthcare setting, confident but incorrect output is particularly important to account for.

01 Prompt and context design matter.
02 AI output requires appropriate boundaries.
03 User experience determines usefulness.
